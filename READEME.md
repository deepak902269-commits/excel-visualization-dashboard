# Excel Visualization Dashboard

A Django web application that allows users to upload Excel/CSV files and generate visualizations.

## Features

- User Registration/Login
- Excel Upload
- Data Preview
- Bar Chart
- Line Chart
- Pie Chart
- Scatter Plot
- Histogram
- Visualization History
- PNG Download

## Technologies

- Django
- Pandas
- Matplotlib
- SQLite
- Bootstrap

## Installation

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
